# شبح — Shabah

مكتبة `dylib` لنظام iOS (الإصدار 15 فما فوق) تُحقن داخل تطبيق وتتحكم في الموقع الذي يراه التطبيق.

## المميزات

**الواجهة**
- لوحة سفلية بأسلوب خرائط Google، تُسحب إلى ثلاثة ارتفاعات، وفيها أربعة تبويبات: الموقع، المسار، التحكم، المفضلة.
- شريط بحث فيه اقتراحات أثناء الكتابة. يقبل اسم المكان أو الإحداثيات أو رابط خرائط Google أو Apple، بما فيها الروابط المختصرة `maps.app.goo.gl`.
- أنماط خريطة: عادي، قمر صناعي، هجين، ليلي.
- زر شبح عائم:
  - الضغط عليه يفتح الخريطة.
  - الضغط المطوّل يفتح قائمة سريعة: إيقاف أو استئناف التزييف، عصا التحكم، المفضلة، الأخيرة.
  - يمكن سحبه، ويلتصق بأقرب حافة.
- واجهة عربية وإنجليزية، مع اتجاه كامل من اليمين لليسار للعربية.

**الحركة**
- عصا تحكم تبقى فوق التطبيق حتى بعد إغلاق الخريطة، وفيها زر قفل الاتجاه.
- مسار متعدد النقاط يتبع الطرق الحقيقية، مع إيقاف مؤقت واستئناف وشريط تقدّم.
- سرعة من 1 إلى 200 كم/س، مع اختيارات جاهزة (مشي، دراجة، سيارة). تغيير السرعة يطبَّق فورًا أثناء السير.
- تكرار المسار ذهابًا وإيابًا.
- حركة واقعية: تباطؤ عند المنعطفات، وتغيّر بسيط في السرعة، وتوقفات قصيرة.
- انتقال تدريجي للموقع الجديد بدل القفز المباشر.

**الواقعية**
- تذبذب ذكي: الموقع يتحرك ببطء داخل نصف القطر الذي تحدده، بدل القفزات العشوائية.
- دقة GPS متغيرة، وارتفاع قابل للتعديل.
- إيقاف تلقائي للتزييف بعد مدة تختارها.

**الإدارة**
- المفضلة: حفظ، إعادة تسمية، ترتيب، حذف، تصدير واستيراد عبر الحافظة.
- سجل آخر 15 موقعًا.
- إعدادات منفصلة لكل تطبيق تُحقن فيه المكتبة.
- سجل تشخيص يمكن نسخه، وتنبيه عند صدور إصدار جديد على GitHub.

## الجديد في 1.1
- **جدولة أسبوعية:** تختار الأيام ووقت البداية والنهاية والمكان. يثبّت شبح المكان تلقائيًا في بداية الفترة ويوقفه في نهايتها.
- **إشعارات:** تنبيه قبل الإيقاف التلقائي بـ 5 دقائق، وتنبيه آخر عند الإيقاف.
- **شريط حالة عائم فوق التطبيق:** يعرض الحالة والوقت المتبقي ونسبة تقدّم المسار. الضغط عليه يوقف التزييف أو يستأنفه، والضغط المطوّل يفتح الخريطة.
- **تخصيص الزر العائم:** الحجم والشفافية، وخمسة ألوان للواجهة.
- **إظهار الزر بأزرار الصوت:** اضغط زر الصوت 3 مرات بسرعة لإظهار الزر المخفي (اختياري).
- **دبوس رمادي للموقع الحقيقي** على الخريطة أثناء التزييف.
- **مناطق الإشعار الجغرافي (Geofence):** تطابق الموقع المزيّف، فتصل أحداث الدخول والخروج للتطبيق.
- **التطبيقات القديمة:** دعم واجهة تحديث الموقع القديمة التي ما زالت تستخدمها.
- **المسارات:** حفظ المسارات وإعادة استخدامها.
- **النقل والحفظ:** زر لنسخ الإحداثيات، وتصدير واستيراد المفضلة والمسارات عبر ملف أو الحافظة.

## البناء
كل `push` يبني المكتبة تلقائيًا عبر GitHub Actions.
بعد انتهاء البناء نزّل الملف من تبويب **Actions**، ثم افتح آخر تشغيل، ثم **Artifacts**، ثم `Shabah-dylib`.

على Mac أو WSL مع Theos:
```bash
export THEOS=~/theos
make FINALPACKAGE=1
```

## الحقن في تطبيق
استخدم أداة توقيع تدعم حقن الـ dylib، مثل Sideloadly أو ESign أو Feather.
ضع `Shabah.dylib` في مجلد `Frameworks` داخل التطبيق، ثم أعد التوقيع.

## الملفات

| الملف | الوظيفة |
|---|---|
| `SHInit.m` | نقطة التشغيل |
| `SHLocationHooks.m` | اعتراض `CLLocationManager` و`MKUserLocation` |
| `SHPersistence.m` | الحالة والإعدادات والمفضلة والتذبذب الذكي |
| `SHMovementEngine.m` | المسارات وعصا التحكم والانتقال التدريجي |
| `SHOverlay.m` | زر الشبح، والقائمة السريعة، والعصا فوق التطبيق |
| `SHMapPickerViewController.m` | شاشة الخريطة واللوحة السفلية |
| `SHBottomSheetView.m` | اللوحة السفلية القابلة للسحب |
| `SHJoystickView.m` | عصا التحكم |
| `SHLinkParser.m` | قراءة الإحداثيات من الروابط |
| `SHSettingsViewController.m` | الإعدادات |
| `SHUpdateChecker.m` | التحقق من التحديثات |
| `SHTheme.m` | الألوان وشعار الشبح ومكونات الواجهة |
